# talk_data — data files for the ten animations

Made by Job 54 (2026-11-12). Repository `HSYMT`, branch `MM_playground`, HEAD `74cdf93`; every script named below is uncommitted (staged) at that HEAD. Check everything with `python talk_data/check.py`.

**All sky-based files use the corrected machine** (every source's pulsar term carries its own random phase; see `JOB54_DATA.md`). Unless a line says otherwise: **natural skies** (raw population draw, one population per sky, each source's own chirp mass), census priors, source parameters of the known set granted, joint fit, retardation on, fine distance grid, timing ×1, 45-year span, 79 pulsars per sky. "Right" = recovered distance within 0.25 pc of the truth. K = 6 σ_d / (tooth spacing).
